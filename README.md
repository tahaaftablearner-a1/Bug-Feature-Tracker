# Bug & Feature Tracker

## Project Description
A simple Python terminal application to record software bugs and feature requests, view recorded entries, and display summary statistics.

## Features
- Add an Entry (Bug/Feature with Priority and Status)
- View All Entries
- Display Summary Statistics
- Menu and Navigation
- Input Validation

## Technologies Used
- Python
- Git & GitHub

## How to Run
Run the application from your terminal using:
```bash
python main.py
